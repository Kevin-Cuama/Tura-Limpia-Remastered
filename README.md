# ♻️ Tura Limpia

**Tura Limpia** es una plataforma web orientada a la gestión y planificación de las operaciones de recolección, que permite administrar de manera centralizada la información relacionada con vehículos, conductores, barrios, rutas, y programación de servicios.

La solución busca facilitar la organización de los recursos operativos mediante una interfaz administrativa que permita registrar, consultar, actualizar y controlar la información necesaria para la ejecución de los servicios de recolección. Además, la plataforma propocionara herramientas de visualización y seguimiento mediante indicadores y reportes que apoyen la toma de decisiones operativas.

---

## 📂 Estructura del Repositorio

* `Backend/` — Lógica del servidor, APIs y servicios.
* `Base de datos/` — Scripts, modelos y configuración de la base de datos.
* `Documentación/` — Manuales, diagramas y documentación técnica del proyecto.
* `Frontend/` — Interfaz de usuario y componentes web.
* `Evidencias/` — Registros, capturas y soporte de pruebas/avances.
